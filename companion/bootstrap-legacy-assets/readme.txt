Keeps loading Bootstrap 3.4.1 (CSS, JavaScript, Glyphicons) after the Bootstrap Shortcodes plugin is removed.

== Description ==

A compatibility bridge, generated by the Bootstrap Shortcodes plugin's migration page. It loads exactly the frontend files that plugin loaded, and nothing else: no shortcodes, no editor buttons, no admin tooling. Three switches under Settings > Legacy Bootstrap turn the CSS, the JavaScript and the tooltip initialiser on or off.

**Bootstrap 3 is end-of-life.** 3.4.1 (February 2019) is its last release. Keeping it running is a deliberate choice made for content that still depends on it; the plan should be to migrate that content and deactivate this plugin.

It avoids double loading: while Bootstrap Shortcodes is active and loading its assets on every page, this plugin does nothing; with that plugin's conditional loading on, this plugin covers the pages it skips. If the theme registers its own bootstrap.css or bootstrap.js, the matching file here is skipped.

The CSS switch also loads Bootstrap Shortcodes' small shortcodes.css (old icon-* sprite icons and layout fixups), as that plugin did.
