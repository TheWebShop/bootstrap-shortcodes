WordPress plugin to add shortcodes for Bootstrap 3. In maintenance mode: kept safe for existing sites, with a documented path off it.

== Description ==

## Maintenance mode

This plugin was written in 2013 for Bootstrap 3 and the TinyMCE editor. It is still maintained for **security and compatibility** so the sites that use it keep working, but no new components will be added. If you are starting a new site, use the block editor's own Columns, Buttons, Details, Accordion and Tabs blocks instead. If you already use it, a component-by-component migration guide and tooling ship in the next release; the [compatibility policy](https://github.com/TheWebShop/bootstrap-shortcodes/blob/master/docs/compatibility.md) says what is tested today.

Bootstrap Shortcodes allow quick and easy implementation of Bootstrap 3 components through the TinyMCE rich-editor (Classic Editor). In the block editor the shortcodes still render; the toolbar buttons do not appear.

## Requirements

The plugin works out of the box: it loads Bootstrap 3.4.1's CSS and JavaScript on every page.
If your theme already includes Bootstrap 3, uncheck "Load Twitter Bootstrap css file" and "Load Twitter Bootstrap javascript file" under Settings > BS Shortcodes so it isn't loaded twice. The "Conditional loading" setting (off by default) loads the files only on pages whose content uses the shortcodes; leave it off if other parts of your site rely on the plugin's Bootstrap.

The plugin makes no external requests and does not track users. Dependency scan state and results stay in your own database until you discard them or uninstall the plugin.

## Supported Shortcodes

We add a row of buttons to the bottom of your post editor Visual mode, each of which gives options for inserting Bootstrap's most popular components.

### CSS

* Alerts
* Buttons
* Grid (container, row, columns, fully responsive)
* Icons
* Labels
* Lead Text
* Wells

### JavaScript

* Collapse
* Tabs
* Tooltip

## Support

Please report issues directly to our [Github repository](https://github.com/TheWebShop/bootstrap-shortcodes/issues).

== Installation ==

1. Unzip files.
2. Upload the folder into your plugins directory.
3. Activate the plugin.
4. Add new shortcodes to posts or pages.

== Frequently Asked Questions ==

= Does the plugin send any data anywhere? =

No. It makes no external requests and has no tracking. The dependency report under Tools can produce a summary of shortcode usage counts that you may choose to send to the author yourself; nothing is sent by the plugin. Details: https://github.com/TheWebShop/bootstrap-shortcodes/blob/master/docs/privacy.md

= How do I stop using this plugin? =

Tools > Bootstrap Shortcodes: scan, preview, migrate (per post or in batches, with rollback), then decide whether anything still needs Bootstrap 3 itself. The full component-by-component guide: https://github.com/TheWebShop/bootstrap-shortcodes/blob/master/docs/migration.md

= How do I find out what on my site uses these shortcodes? =

Tools > Bootstrap Shortcodes scans posts, pages, custom post types, widgets, options, custom fields, term descriptions and your theme's PHP files, and lists what it found and what it could not check. On the command line: `wp bs-shortcodes scan`.

= There is no Button in the Visual Editor =

You must toggle the Advanced Editor Toolbar to unlock the Bootstrap Shortcodes icons. (see screenshot)
